# 企业微信日程管理 Skill

面向 Codex / OpenClaw 的企业微信日程管理 Skill，用于通过企业微信开放接口管理日历、日程、参会人、会议补建和审计日志。

## 主要功能

- 解析企业微信用户身份，支持 `userid`、手机号、邮箱、姓名
- 当未显式提供组织者时，支持回退到企业微信会话发送人作为默认组织者
- 创建、查询、更新、取消企业微信日程
- 按成员、部门名称、组织路径或自然语言组织短语批量解析参会人
- 支持创建后追加会议，并保持 `schedule_id -> meeting_id` 关联
- 支持用户级 `cal_id` 本地绑定与审计日志记录

## 使用前提

- 仅适用于企业微信场景
- 需要企业微信自建应用，并开通通讯录、日历、日程、会议、消息等对应权限
- 需要为应用配置可见范围，否则姓名解析和组织识别会受限
- 如企业微信启用了可信 IP，调用机器的公网出口 IP 也需要提前加白

## 适用范围

适合：

- 企业微信自建应用场景
- 需要可审计日程管理的助理 / 自动化流程
- 需要先识别组织再一次性创建完整日程的场景

不适合：

- 邮件、短信、飞书、钉钉等非企业微信渠道
- 统一管理所有平台会议系统
- 管理其他应用或员工手工创建的普通日程

## 关键限制

- 默认只能稳定管理当前应用创建或绑定的 `cal_id` 下的日程
- 员工在企业微信客户端手工创建的普通日程，通常不在这个 skill 的稳定管理范围内
- 会议补建建议基于未来时间的日程执行；过去时间会被企业微信拒绝
- 测试数据建议通过 `cancel-schedule` 清理，脚本会同步移除本地 `schedule_id` 关联上下文
